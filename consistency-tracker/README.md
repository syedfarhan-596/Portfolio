# Consistency Tracker

A local-only Android app that turns a real daily routine into a system for
building consistency — grounded in *Atomic Habits* (make it obvious, attractive,
easy, satisfying). No account, no cloud; everything stays on the device.

**Status:** 📐 Planning. See [`docs/DESIGN.md`](docs/DESIGN.md) for the full
design, feature list, screens, tech stack, and data model.

## The idea in one line
Two tracks — **maintenance habits** (daily, one-tap, streaks) and **growth
skills** (DSA / dev / reading on a 2-days-a-week focus schedule) — visualized as
a GitHub-style green consistency grid.

## Planned stack
Kotlin · Jetpack Compose · Material 3 · Room (local DB) · WorkManager · Glance widget
